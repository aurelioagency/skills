# Starter asset catalog

This catalog is populated from the approved Video Animation Workflow reference production.

## Library routes

| Path | Purpose |
|---|---|
| `assets/starter-library/images/production/` | Production-ready isolated raster assets |
| `assets/starter-library/images/source/` | Untouched ImageGen source outputs and generation-chain evidence |
| `assets/starter-library/sfx/` | Semantic sound effects named by footage purpose |
| `assets/starter-library/fonts/` | Redistributable open-source starter fonts and their license texts |
| `assets/starter-library/guides/` | Typography, caption, Reel safe-zone overlay, motion, and sound usage rules |
| `assets/reference-projects/youtube-16x9/` | Editable 1920×1080 HyperFrames reference composition |
| `assets/reference-projects/reel-9x16/` | Editable 1080×1920 HyperFrames reference composition |
| `assets/reference-proof/storyboards/` | Approved storyboard sheets for both formats |
| `assets/reference-proof/snapshots/` | Approved checkpoint/contact-sheet evidence |
| `assets/reference-proof/renders/` | Final reference MP4s |
| `assets/reference-proof/imagegen-prompts/` | Prompts used to create missing storyboard and production assets |
| `assets/manifest.json` | File inventory, purpose, provenance, and SHA-256 |

## Usage rule

The library is a starter system, not a fixed brand preset.

1. Resolve the user's brand profile.
2. Search the user's assets first.
3. Reuse a starter asset when its meaning fits.
4. Adapt color or tone only when the approved source supports editing and the user approves the change.
5. Generate a new asset when reuse would misrepresent the user's brand or subject.

Never place text from the reference production into a new video merely because its animation already exists. Reuse the motion mechanism or component, then replace the content through the approved script and storyboard.
