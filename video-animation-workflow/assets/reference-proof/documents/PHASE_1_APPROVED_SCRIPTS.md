# Fase 1 — Guion maestro aprobado

Fecha de aprobación original: 2026-07-28.
Última corrección de alcance: 2026-07-28.

## Promesa aprobada

La skill permite generar animaciones profesionales para un video. Se entrega como una base reutilizable que contiene:

- el workflow usado para producir esta introducción;
- los assets utilizados en el video;
- directivas para adaptar colores, tono y estilo a la marca del usuario.

La promesa no incluye generar varias piezas de contenido al mismo tiempo.

## Guion maestro — YouTube 16:9 y Reel 9:16

> ¿Querés que tus videos se vean así sin animar todo a mano? Diseñar captions, buscar assets y sincronizar movimientos lleva tiempo. Esta introducción se construyó con el workflow que voy a compartir. Y todas estas animaciones las generé con una skill para Claude, adaptable a ChatGPT o Gemini. Recibís la skill con el workflow, los assets y directivas para personalizar color, tono y estilo de marca. No empezás de cero.

- Palabras: 70.
- Duración hablada estimada: 30 segundos a 140 palabras por minuto.
- Hook autónomo: `¿Querés que tus videos se vean así?`
- Narración, orden de frases y timing: idénticos en ambos formatos.
- La composición de cada plano se diseña de forma nativa para 16:9 y 9:16; el Reel nunca será un recorte del master horizontal.
