# Reference compositions

These two HyperFrames projects are the editable source of the approved 30-second demonstration:

- `youtube-16x9`: 1920×1080
- `reel-9x16`: 1080×1920

They share script, timing, narrative, asset identity, and sound design, but use separately authored layouts.

The approved reference MP4s used the creator's locally licensed Helvetica and Shelley files. Those font binaries are not redistributed here. The editable public copies use bundled Inter Variable and Playfair Display Italic Variable under the SIL Open Font License 1.1. Users should replace the typography with their active brand profile rather than treating either font pair as mandatory.

The voice-over file is included only to reproduce and study synchronization in the noncommercial reference project. It is not a default voice and must not be reused as another creator's identity.

Run the current `/hyperframes` workflow and its CLI checks before rendering. The projects are evidence and reusable motion source, not permission to skip the Video Animation Workflow approval gates.
