# Script aprobado

¿Querés que tus videos se vean así sin animar todo a mano? Diseñar captions, buscar assets y sincronizar movimientos lleva tiempo. Esta introducción se construyó con el workflow que voy a compartir. Y todas estas animaciones las generé con una skill para Claude, adaptable a ChatGPT o Gemini. Recibís la skill con el workflow, los assets y directivas para personalizar color, tono y estilo de marca. No empezás de cero.
